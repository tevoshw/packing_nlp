# Sequence Packing

## What is it?

**Packing** (or *sequence packing*) is a technique that joins tokens from multiple documents into a continuous stream and cuts that stream into fixed-size blocks (`seq_len`), so every training sample has exactly the same length.

Training batches need uniform shapes. Instead of padding short texts or truncating long ones, packing fills each block completely with real tokens.

## How it works

1. Tokenize each document.
2. Append an `<eos>` token at the end of each document.
3. Concatenate everything into one long stream of tokens.
4. Cut the stream into blocks of `seq_len` tokens.
5. Each block becomes one training sample.

```
Doc A: [a1 a2 a3 <eos>]
Doc B: [b1 b2 <eos>]
Doc C: [c1 c2 c3 c4 <eos>]

Stream: a1 a2 a3 <eos> b1 b2 <eos> c1 c2 c3 c4 <eos>

seq_len = 5
Sample 1: a1 a2 a3 <eos> b1
Sample 2: b2 <eos> c1 c2 c3
Sample 3: c4 <eos> ...
```

A *token buffer* is typically used internally: tokens are accumulated until there are enough to emit a full block.


## Where it is used

- **Pre-training:** the standard approach. Text is treated as one continuous stream.
- **SFT (Supervised Fine-Tuning):** also common, to avoid wasting compute on padding. Each example is independent, so a **per-example attention mask** (or reset `position_ids`) is usually applied so one example does not attend to its neighbor in the same block.

## Advantages

- **No padding:** no compute wasted on `<pad>` tokens.
- **Uniform batches:** every sample has the same length.
- **Better GPU utilization:** higher throughput.

## Caveats

- A block may contain the end of one document and the start of another.
- Without proper attention masking, the model can attend across document boundaries (cross-contamination).
- In SFT, loss masking (ignoring prompt tokens) must still be preserved after packing.

## Alternative: padding + truncation

| | Packing | Padding + truncation |
|---|---|---|
| Sample length | Fixed, filled with real tokens | Fixed, filled with `<pad>` |
| Wasted compute | None | Depends on length variance |
| Typical use | Pre-training, efficient SFT | Classification, simple fine-tuning |

## Related terms

- **Chunking / grouping:** Hugging Face's `group_texts` function does the same cut-into-blocks operation.
- **Dynamic padding:** pad only up to the longest sample in each batch.
- **Bucketing:** group samples of similar length in the same batch.
